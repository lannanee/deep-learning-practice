## Deep Learning là gì?

Deep Learning là một nhánh của Machine Learning, sử dụng **mạng nơ-ron nhân tạo nhiều lớp** để tự động học các đặc trưng từ dữ liệu thô (ảnh, văn bản, âm thanh, chuỗi thời gian...) mà không cần thiết kế đặc trưng thủ công.

**Các khái niệm cốt lõi**
- **Neuron và lớp (layer)**: đơn vị tính toán cơ bản, xếp chồng thành mạng.
- **Hàm kích hoạt (activation)**: ReLU, Sigmoid, Softmax...
- **Hàm mất mát (loss)**: đo sai lệch giữa dự đoán và thực tế.
- **Lan truyền ngược (backpropagation) và tối ưu hóa**: SGD, Adam.
- **Overfitting và regularization**: Dropout, Batch Normalization, Early Stopping.

**Các kiến trúc chính**
| Kiến trúc | Dùng cho |
|---|---|
| MLP / Neural Network cơ bản | Dữ liệu dạng bảng |
| CNN | Ảnh, thị giác máy tính |
| RNN / LSTM / GRU | Chuỗi, văn bản, chuỗi thời gian |
| Transformer | Xử lý ngôn ngữ, mô hình ngôn ngữ lớn |
| Autoencoder / GAN | Nén dữ liệu, sinh dữ liệu |
